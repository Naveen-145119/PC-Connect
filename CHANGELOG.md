# Changelog

## 0.2.0-preview.2 — 2026-11-07

- Fixed a crash when selecting the office laptop role or changing the screen arrangement in Pair devices.
- The secondary laptop IP field now follows the selected role when restoring settings or disconnecting.

## 0.2.0-preview.1 — 2026-11-06

- First public open-source preview, MIT license and Windows build/release automation.
- Native graphite/amber UI with pairing, visual arrangement, transfers and diagnostics.
- Per-user Windows installers with bundled .NET, application icon, desktop/Start menu shortcuts, Installed apps registration, upgrade and uninstall support. Separate x64 and ARM64 downloads.
- Continuous held-button cross-screen **copy** bridge with authenticated one-use drag permits, verified materialized files, ordered activation, cancellation and native destination OLE loop. Both directions use the primary mouse; preparation waits at the edge. Protocol version 2 requires updating both peers.
- 26 automated regression tests, including two-process mutual TLS/reconnect/bidirectional transfers/drag exchange, plus successful interactive local OLE handoff.
- Clear setup, office network, architecture, contribution, security and hardware-validation documentation.

Physical two-laptop and ARM64 runtime qualification remain pending. Preview installers are unsigned.
